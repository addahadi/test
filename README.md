# Study Task Tracker — Git & GitHub Workshop

A small, working browser app for learning Git in VS Code.

## Run it

1. Open this folder in VS Code (`File > Open Folder`).
2. Double-click `index.html` to open it in a browser, or use VS Code Live Server.
3. Add, complete and delete tasks. Tasks are stored in your browser's `localStorage`.

**No Node.js, npm or backend required.**

## Workshop goals

- `git init`, `git status`, `git add`, `git commit`, `git log`
- `git switch -c`, `git branch`, `git merge`
- Practice a merge conflict using the heading in `index.html`
- `git remote`, `git push`, `git pull`, `git clone`
- Open a pull request on GitHub

The starter project intentionally contains **no `.git` folder**: you will create it during the lesson with `git init`.

See the separate instructor guide for the exact live-demo sequence.
